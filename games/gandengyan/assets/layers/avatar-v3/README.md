# 紫色机器人头像素材 v3

使用内置 imagegen，参照 `设计稿/05-01 个人中心-更换头像.jpg` 重新生成简洁的紫色胶囊机器人。原始生成图保留为 `parts-atlas.png`，完整生成提示词见 [generation-prompt.txt](generation-prompt.txt)。

透明素材：`head-1.png` 至 `head-5.png`、`eyes-1.png` 至 `eyes-5.png`、`mouth-1.png` 至 `mouth-5.png`。由 Sharp 按实际 alpha 边界切分，保留三个像素的抗锯齿边距。

部件 1 是中央默认款。头盔依次为紫银、橙灰、银绿、红青、银色耳罩；眼部依次为绿色短眼、黑色墨镜、紫色窄缝、青色圆眼、黑色宽面罩；嘴部依次为黑色呼吸孔、蓝色格栅、银色分节、白色插片、银色方片。

组合 ID 保持 `p头部-眼部-嘴部`。512 单位画布中，眼部提供完整紫色面罩，嘴部经过纵向渐变遮罩叠加下半段，最后叠加透明头盔。缩略图中眼部与嘴部均显示完整紫色面罩，头盔显示中性面罩和装甲。

验证：浏览器检查 15 个部件切换与随机组合；检查桌面及手机端个人中心；检查五个组合头像在五人游戏布局中的显示。预览见 `profile-desktop-preview.png`、`profile-mobile-preview.png`、`battle-desktop-preview.png`。

旧版 a1–a12 的存储格式及既有头像保持兼容。新素材用于个人中心部件选择及 p1-1-1 等组合头像，保存后通过既有同步流程显示在大厅和游戏中。
