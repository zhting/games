# 对战画面素材 v2

使用内置 image_gen 生成，参考用户提供的第二张设计图。文字、牌点、玩家名和计时数字由实时 DOM 叠加，素材只包含外观。原素材未覆盖。

13 个独立透明 PNG 位于本目录；sources/ 保存三张生成原图；manifest.json 记录拆分坐标。art-extract-battle.cjs 可重复拆分原图，保留原 alpha。

倒计时底座使用新生成的 timer-housing-v2.png，包括灰蓝金属圆环、六边形背板和左右连接轴。ui.js 在素材上绘制凹槽、蓝色进度条和银色圆盘；圆盘覆盖进度条内缘，进度条侧面及接触阴影采用暗色并同步倒计时。生成提示词见 timer-housing-v2.md。

顶部 HUD 使用 hud-rail-wide.svg，在原素材左右两端的空白面板各延长 100 像素（1736 × 190），箭头、连接纹饰和中央部分按原尺寸绘制。两端文字定位随面板调整，文字字号保持不变。
