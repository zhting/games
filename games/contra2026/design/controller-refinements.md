# 手柄与场景修正（仅本地试玩）

第三关保留在 `codex/contra-stage-three` 本地开发分支。本次不推送、不合并线上 main、不部署。

- 移除第三关 Boss 张嘴时额外绘制的两颗红点，保留原生张嘴画面。
- Boss 火球改为更大的空心红橙色环，碰撞半径从 3.2 增为 5，与视觉同步。
- 第三关进洞沿用角色原尺寸，包括巨大化状态；进入过程保留淡出，不再缩放。
- 第二关过门保留房间透视前进，移除横跨屏幕的白色速度线；过门期间旧弹丸继续隐藏。
- 每帧读取新的 Gamepad API 快照，支持系统通过蓝牙或 USB 接入、浏览器识别的标准布局手柄。设备连接、断开、重新连接自动更新状态；断线立即释放方向和按键。设置显示当前设备，未识别时提示按键激活。
- 左摇杆 / 十字键移动和瞄准；A / × 跳跃；X / □ / RB / RT 射击；B / ○ 手雷；Y / △ 特殊道具；LB / LT 切换道具；Start / Options 暂停 / 继续；Back / Share 暂停 / 返回。菜单上下选择、A / X / Start 确认、B 返回；设置支持左右调整和切换唱片。
- 多个手柄只由当前操作的设备提供输入，不将互相矛盾的方向合并；新按键可切换设备。

连接方式由操作系统处理。网页 API 不提供 USB / 蓝牙传输类型或系统配对入口。浏览器可能在用户按下手柄按键后才暴露已连接设备，参见 [MDN Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)。

验证记录：新增标准按键、摇杆死区、十字键、模拟扳机、多设备切换、断线重连和接口故障测试；真实引擎测试移动、射击、跳跃、手雷、特殊道具、暂停及断线释放。画面测试覆盖张嘴无红点、进洞尺寸不变及过门不绘制白色速度线。浏览器验证截图与记录位于 `.playwright-mcp/controller-refinements/`。

系统可见 Xbox 控制器设备。自动验证使用模拟 Gamepad 快照；尚未进行实体蓝牙或 USB 手柄按键实测。

最终结果：独立分支全部 175 项魂斗罗测试通过，`git diff --check` 通过。Ego-browser 空间 203 核对了张嘴与大环形弹、入洞四个时点的相同画面缩放、第二关前进画面、完整样式下的手柄设置、菜单与唱片操作及断线重连。正常 3190 页面不含测试注入，游戏服务保持运行。
