# 魂斗罗2026 · 封面与第一关视觉方案

## 视觉方向

以 1988 年 NES / FC《魂斗罗》的像素界面为参考：黑底、红金金属字、红蓝双人、层叠绿叶与赭色岩台、钴蓝河流及灰蓝机械要塞。参考入口：[KONAMI 官方周年合集](https://www.konami.com/games/50th/ac/contra/asia/en/)。两张图使用内置 image_gen 生成，完整提示词见 `prompts.json`。

封面用于合集缩略图和游戏标题左侧主视觉，右侧只保留单人、联网、选关及设置。选择焦点沿用奖章光标；场景保留分层滚动，命中及无敌闪烁帮助识别状态，不增加装饰性界面动画。

## 第一关设计

`stage-01-v2.png` 上部展示双人同屏场景，下部展示整关路线与颜色配置。

| 顺序 | 场景 | 操作节奏 |
| --- | --- | --- |
| 01 | 空降起点 | 安全落点、认识红蓝两位玩家与共享镜头 |
| 02 | 丛林岩台 | 高低台阶、斜向射击、武器胶囊 |
| 03 | 爆破桥 | 桥面分段爆破，双人同步前进 |
| 04 | 河流 | 水面与岩台形成上下两条路线 |
| 05 | 炮台阵地 | 固定炮台与胸口高度的子弹，鼓励卧倒和跳跃 |
| 06 | 机械要塞 | 两个炮口与醒目的核心弱点，完成关底战斗 |

HUD 以 1P / 2P 红蓝身份和清晰的分数、生命为主；玩家上方加同色标签。敌人与子弹保持高对比，小道具用字母识别。镜头避免把落后的存活玩家挤出屏幕，垂直关卡同样保留两人的可见范围。

设计板现已落地为第一关可玩版本。逻辑坐标仍为 384×216，绘制画布按窗口和设备像素密度调整，最高 3840×2160；精灵缓存保留相应显示精度和透明边缘。文字使用原生字体，水纹、弹道及枪口光使用细线和抗锯齿绘制。背景、角色及环境资源按 [资源清单](stage-01-assets.md) 接入，高清截图为 [stage-01-hd.png](stage-01-hd.png)。

岩台改为高低错落的地形，角色出生点、补给箱和炮台按支撑面放置。桥梁仍分段触发爆破；河流保留入水与潜伏行为。要塞的炮口、核心、子弹生成点和装甲阻挡通道共用新坐标，并由引擎测试验证命中。单人及双人联网使用同一套第一关美术，其他十五关继续使用各自的原渲染。
