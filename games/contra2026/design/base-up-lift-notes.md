# 第二关顶部 Boss 上射与升降平台

顶部移动装置出现后，按住 W / ↑、手柄上方向或触控上方向可以举枪，配合射击键攻击顶部。松开上方向恢复普通投射高度；向上举枪时仍可左右移动和跳跃。普通房间的高位机关继续使用跳跃射击，关底仍先摧毁六个下层装置，再启动顶部 Boss。

红蓝新姿势来自内置 image_gen，原生透明 PNG 为 [commando-upward-v1.png](../assets/stage2/commando-upward-v1.png)。完整提示词及参考素材记录在 [base-up-lift-art.json](base-up-lift-art.json)。图像保留原尺寸 1536 × 1024，未覆盖既有角色图集。

`js/base-actor-poses.mjs` 共用原画裁切、腰带、脚底与枪口锚点，举枪时保持原角色的头至脚底身高。移动时与原有八帧背视跑步合成完整角色帧，再统一绘制无敌描边和隐身效果。真实子弹与枪口火光使用同一枪口位置，巨大化时一并缩放。

两侧升降平台只保留底板，移除外框、梯级和封闭井道。底板持续跟随乘梯角色，跨过原先 87 单位高处的显示截断，直到从顶部升出屏幕。已升出的底板不会重新出现在地面；双人模式继续等待存活队友一起进入第三关。Boss 摧毁时清除残留弹丸，等待和乘梯阶段不再发射新弹丸，旧快照也不会留下静止的子弹或枪口光。
