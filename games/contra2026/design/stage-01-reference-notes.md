# 第一关原作录像观察

参考文件：用户提供的 `H:/download/videoplayback.mp4`（640×360，约 16 分 50 秒）。检查了第一关的落地、河岸、断桥、树林平台、炮台与关底，并提取了翻滚和桥梁爆破的连续帧。

- 岩壁是连续地形表面：大小不一的斜向石块错缝排列，草沿覆盖上缘，不能露出素材图块的外框或每块重新起算的横线。
- 草地、石壁与水面形成清楚的可行走轮廓；背景树干向地面延伸，不能让整棵树随背景视差脱离落脚点。
- 跳跃采用抱膝连续翻转，接触地面后恢复持枪站姿；只切到一张抱膝图不足以表现翻滚。
- 桥梁沿前进方向分段爆破，爆炸消退后桥段确实消失；火光不能长期盖住可落脚的位置。
- 后段树林以树冠与纵向树干构成背景，角色和敌弹保持清楚的轮廓。当前版本保留高清绘制与中文界面。

这段第一关从玩家进入场景开始，没有可直接对照的直升机和流星镜头。它们属于本作增加的开场：旋翼需独立旋转，流星需有渐隐尾焰和碎屑，人物从飞机落下后要有翻滚与落地收势。

实现对应 `js/stage-one-scenery.mjs`（连续世界几何、树根锚点、下落轨迹）与 `js/stage-one-art.mjs`（旋翼、翻滚、尾焰及岩壁细节）。
