# 首关加载与生命规则修复

2026-10-28。首关冷启动准备资源从 24 项降到 21 项；其他关卡分别为 20、24、18、25 项（配乐开启）。

图片减少 30.8%，上述媒体合计减少 24.8%。该统计不含 HTML、脚本及字体，属于资源体积对比，不代表所有网络环境中的加载时长。

- 共享肢体跑步图集已覆盖红蓝角色及敌兵，因此从下载队列移除三张旧整人跑步图集，省下 960,742 字节。兼容文件和图集定义仍保留。
- 从原始 PNG 再编码 14 张 WebP，额外省下 584,216 字节。不缩放图集，透明通道逐像素保持一致，角色裁切和碰撞不变。
- 可见区域 PSNR 以 32 dB 为压缩下限；原资源本已低于此值的图片不降低原有质量。逐图参数、哈希、尺寸见 `startup-optimization.json`。原始母版保留，工具为 `../tools/optimize-startup-images.py`，需 Node.js、Python 和 Pillow。
- 首关配乐已为约 64 kbps Opus，本次保留音质与完整长度。
- 资源 URL 的 `v` 使用内容哈希；Vercel 仅为匹配十位十六进制版本号的游戏资源设置一年 immutable 缓存。页面、脚本及无版本号音频仍按原规则更新。配置采用 [Vercel 的条件 headers 规则](https://vercel.com/docs/project-configuration/vercel-json)。

普通难度默认 3 条命，简单难度 5 条命。旧 v2 设置中继承的无限生命默认值迁移为关闭，新 v3 保存的主动选择继续保留。PC 秘籍改为标题画面 **↑ ↑ ↓ ↓ ← → ← → B A B A**；旧十键前缀不激活，手机八次轻点方式不变。
