# 横版角色连续跑步

视觉方向：保留手绘上身与持枪姿态，以连续脚步、轻微重心起伏、前后腿遮挡和固定落脚点表现向前奔跑。

原十二张姿势图包含重复跨步和不一致的躯干/脚掌位置。正式横版红蓝角色及敌兵在素材加载后使用连续腿部运动；旧图集保留作为兼容回退。

新素材 `assets/stage1/runner-limbs-hd.png` 是内置 image_gen 生成的原生 1086×1448 RGBA，三个配色各包含近/远侧大腿与小腿靴子。生成记录在 `run-rig-prompts.json`。运行时使用原画裁切、固定骨长与矢量裁切，未修改 PNG 的像素或透明通道。上身仍用现有原画，腰部通过弧形骨盆区域衔接；前后腿有独立明暗，脚踝与靴子分别旋转。

`stage-one-motion.mjs` 的 runGait 直接驱动实际绘制。玩家周期距离 42、敌兵 36 逻辑像素，支撑相位 38%，腿之间相差半周期；每周期两次短暂腾空。摆动脚使用端点速度匹配的 Hermite 轨迹，脚掌离地后回收抬起、落地保持水平。髋、膝、踝保持固定骨长，躯干有轻微前倾和重心起伏。相位跟随同步中的现有 anim 与速度，不向联机快照写入图像或渲染缓存。

验证：正反方向及不同速度/尺寸的支撑脚世界坐标固定，关节长度不变，脚部轨迹在蹬地和落脚时一阶连续，实际绘制在小于一帧的相位变化时仍连续改变关节。缓存后的真实靴底也与地面坐标对齐。54 项专项测试通过，包含第二关独立背视绘制与联机回归。

实机关键相位：`run-rig-phases.png`。游戏实际渲染的 56 帧以 60 fps 保存为 `run-rig-preview.mp4`，对应画面为 `run-rig-game.png`。临时测试钩子仅存在于 3192 的预览，正式 3190 入口不包含它们。

正式入口已实际验证向右跑、向左跑、持枪射击、松键停止与暂停。14 张素材全部加载，运行异常为 0；记录为 `run-rig-qa.json`。
