# 魂斗罗2026 · 前两关试玩

当前开放第一关「雨林要塞」和第二关「地下指挥所」，支持单人和双人联网同屏。后续关卡保留开发代码，暂不提供入口。

## 运行

在仓库根目录使用 Node.js 22 或更高版本，执行 `npm ci`、`npm start`，打开 `/games/contra2026/`。

## 游戏流程

首次单人开局、选关或创建/加入联机房间时，先准备前两关的 27 张运行图片、10 张唱片图、10 首音乐及字体（共 48 项）。加载时游戏不计时，显示进度并支持失败重试和返回标题；成功资源在当前页面内复用。音乐提前下载编码文件，只提前解码当前选曲和片头，避免一次展开全部长音轨占用过多内存。

- 第一关：夜间暴雨雨林，多种枪械、手雷、迷彩、护盾、巨大化、摩托车和直升机；要塞核心击破后，角色跳入通道进入第二关。
- 第二关：三个差异化走廊房间，高位机关、红色补给兵及地面掉落；最终战先拆六个装置，再攻击顶部移动装置，击败后乘两侧升降梯完成本次试玩。
- 选关、联机起始关卡与唱片设置只列出前两关。旧隐藏关卡存档和秘籍不能绕过开放范围；服务器校验开局关卡和同步画面。
- 第二关通关后，可重玩本关或返回标题，第三关暂不开放。

## 音乐与设置

音乐以独立唱片图切换。第一关提供原版、YuE2 交响、摇滚、史诗、工业金属、赛博朋克和电子乐；第二关提供原版及电子乐。随机播放仅抽取对应关卡曲目，每次入关抽一次，暂停和房间推进保持本次选择。

## 双人联网

创建房间后把六位房间码或邀请链接交给朋友，双方就位后由房主开始。两人共享镜头、进度、分数和有限生命池，各自拥有武器、道具与手雷冷却。房主运行世界，客机发送按键，服务器中继快照；房主离开会关闭房间。

后台路径为 `/games/contra2026/ws`。生产前端和后台需一起更新，并应用 `backend/deploy/nginx-locations.conf` 中的 WebSocket 路由，详见根目录的后台说明。

## 验证与资源

运行 `node --test backend/test/contra*.test.mjs`；完整仓库检查为 `npm test`。

运行素材位于 `assets/`，渲染、音乐和联机模块位于 `js/`。唱片矢量原稿可使用 `node games/contra2026/tools/draw-music-records.mjs` 重新绘制。

浏览器使用 WebP 图片：角色、植被、机关及其他透明素材采用逐像素无损压缩，保持原尺寸和图集坐标；封面、岩石与走廊背景使用质量 90 的 WebP，合集封面生成 800×800 版本。PNG 原图保留供编辑和图集测量。安装 Pillow 后运行 `python games/contra2026/tools/compress-images.py` 可重新生成，脚本会校验透明素材的完整 RGBA 像素及全部图片尺寸。
