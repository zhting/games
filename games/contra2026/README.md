# 魂斗罗2026

原「赤焰突击」的合集版本。当前试玩开放前八关：「雨林要塞」「地下指挥所」「峡谷瀑布」「地下基地」「极地冰原」「高温能源厂」「机械机库」「异形巢穴」，支持单人和双人联网同屏，后续关卡暂未公开。

在仓库根目录运行 `npm ci`、`npm start`，打开 `/games/contra2026/`。

魂斗罗入口只加载本游戏的依赖；悟空的角色、武术、语音和配乐系统由悟空独立入口加载。标题页实测 JavaScript 模块请求从 125 个降至 64 个，源码传输量约从 1.57 MB 降至 1.12 MB。三格道具的绘制与点击共用布局，单人和房主操作左侧，玩家二操作右侧；第五关也显示双方各自的武器、道具和手雷冷却。实现与发布文件核对见 [入口与道具栏优化](design/entry-inventory-optimization.md)。

点击单人闯关或选关后，只准备目标关卡使用的图片、配乐与字体；进入下一关时再显示进度并准备该关资源，加载期间暂停计时。第一关固定使用压缩后的摇滚重制版，正常开启配乐时首次准备共 23 项，不下载未使用的关卡场景、旧音乐或已由肢体动画替代的三张跑步图集。当前首关图片共 4,039,680 字节，比原始 5,014,622 字节减少约 19.4%；草岩材质与第三关共用，替换后停用的旧岩壁仅随第三关加载，冻结图集跨关复用。带内容版本号的资源配置长期缓存，版本随内容更新。首轮压缩记录见 [首关加载优化](design/startup-optimization.md)。共用人物、机关图集与已下载音乐在当前页面内复用，重玩不重复下载；失败可重试，返回标题会取消本次进入。联机加入房间先获知实际关卡，开始时再加载对应资源，玩家二等待完成后应用最新同步画面。

第二关普通闯关使用提供的 `魂斗罗第2关闯关.mp3`，Boss 战沿用原中枢配乐；第三关全程使用 `魂斗罗第3关.mp3`。两首完整曲目转为 48 kHz、64 kbps Opus，分别约 795 KB / 829 KB，只在进入对应关卡时加载。

## 双人联网

1. 进入「2P 联网同屏」，选择起始关卡，创建房间。
2. 将六位房间码或邀请链接交给朋友，对方点击「加入房间」。
3. 房主点击「双人开始」。玩家一为红色，玩家二为蓝色；两台设备使用相同的 WASD / 方向键、J 射击、K 跳跃、I 手雷、L 道具、Q 切换道具，也支持触屏和手柄。

两人共享镜头、关卡进度、分数与有限生命池，各自拥有武器、道具和手雷冷却。正式网站默认有限生命：普通难度 3 条命、简单难度 5 条命；设置中可主动开启无限生命。本机 localhost / 127.0.0.1 测试默认无限生命，方便调试；两种环境各自保留玩家主动保存的选择。正式网站的旧版无限生命默认值会一次性迁移为关闭。任一方都可以暂停和继续；重开、设置与过关后继续由房主操作。房主切到后台会同步暂停。

第二、四关普通守军横向跑动、跳跃并发射子弹；跳跃高度会同步影响枪口、受击位置与双人快照。第二关 Boss 的六个炮塔各自随机开启下方三联炮口，再同时射出三发子弹；击毁炮塔会停止其攻击。顶部核心使用更细致的机械眼外观，发射的气泡与核心同样大小。

第二、四关向下一房间前进时，立即清掉上一房间的近远景士兵、滚雷和侧门守军；敌方弹道同步清空。该状态写入双人快照，推进期间不再显示残留敌人；已掉落的补给继续随地面推进，下一房间正常恢复出兵。

PC 的 30 条命秘籍：在标题画面输入 **↑ ↑ ↓ ↓ ← → ← → B A B A**，按键间隔不超过 2 秒；看到“30 条命已就绪”后开始游戏。旧的十键序列不再激活。手机仍为标题 Logo 四秒内轻点八次。秘籍生效后死亡扣命，退出本局返回标题即取消。

联机同样开放第 1–8 关。第二关中枢击败后，所有存活玩家乘侧边升降梯进入第三关；第四关双生投影击败后，所有存活玩家分别登梯到顶部，进入第五关；第五关击败最终飞行堡垒后，可从过关界面进入第六关。第六关击败机器人后，所有存活玩家通过右侧大门进入第七关；击破第七关防御大门后进入第八关。队友离开后停止闯关，房主可以等待重新加入再开局；房主离开则房间关闭，不进行房主迁移。

后台端点为 `/games/contra2026/ws`，复用根目录 `backend-config.js` 的统一后台配置。房主以 60Hz 运行世界，2P 按键经服务器发送到房主，20Hz 完整快照同步至 2P，保留平台、桥梁和激光命中的对象关系。服务器限制房间人数、消息大小和发送频率，仅允许房主发送快照。

生产前端与后台需一同发布，并为 Nginx 加入 `backend/deploy/nginx-locations.conf` 中的新 WebSocket 路径；仅发布静态前端不能启用生产联机。

敌人冻结改为按实际人物、武器或炮台轮廓生成薄冰壳，叠加内置 imagegen 生成的霜花裂纹、短冰挂和脚边碎冰，移除原先的矩形线框。解冻前半秒逐渐恢复原材质；冻结持续时间、攻击暂停和伤害规则沿用原逻辑。约 124 KB 的透明 WebP 图集由前五关共用，渲染缓存按显示精度建立，不逐帧回读像素。素材与完整提示词见 [冻结效果记录](design/enemy-freeze-v2.json)，姿势预览见 [冻结材质校准](design/enemy-freeze-preview.html)。

主线玩家死亡后先受击翻倒并下落，碰到地面或平台后切换贴地倒下姿势，停留约 0.3 秒后渐隐，完全消失后再复活。高处死亡会等待落地后的完整过程，桥段消失则继续下落，跌出屏幕直接隐藏。死亡进度与地面支撑一起进入双人快照；生命耗尽的队友遗体消失后保持隐藏。模拟逻辑见 `js/player-death.mjs`，效果见 `design/stage-01-death-sequence.png`。

第一关子弹命中采用材质反馈：金属表面为暖色火星、细碎金属片与少量余烟，核心为蓝白能量闪光，敌兵为较小的碰撞火花和短暂亮起，护盾为蓝色反应。效果锚定碰撞表面并沿射入方向反向散射，要塞原大叉号改为部件局部亮起。单次事件约 0.19–0.29 秒，相邻散弹命中合并，最多同时保留 32 个命中事件；粒子由同步的种子和事件时间绘制。代码见 `js/impact-effects.mjs`，逐帧及连射预览见 `design/stage-01-hit-feedback.png`、`design/stage-01-hit-feedback-4k.png`。

关底要塞保持原设计素材比例，塔顶完整露出，后侧装甲贴住最终镜头右边缘；炮口、核心、墙体阻挡和角色边界共用建筑布局。损毁使用独立透明残骸图集，包含破裂炮管、撕裂装甲、裸露线路与暗色破碎核心；旧机体会移除，余烟与火星随时间消退。核心摧毁时剩余炮口同步变为残骸，损毁时间保存在联机快照中。最新效果见 `design/stage-01-wreck-closeup.png` 和 `design/stage-01-wreck-core.png`。

要塞采用 `assets/stage1/fortress-realistic-v3.webp` 的混凝土风格：承重柱、外露钢筋、深色装甲炮座、液压机构和暖色反应堆都有完整细节；炮台与核心残骸、破损通道同步使用匹配材质。三个 WebP 合计约 1.03 MB，只随第一关加载，沿用原立面、命中和过关坐标。角色跳入后保持原尺寸，向右移动时被洞壁逐渐遮住，随后进入第二关并保留武器和分数。双人模式等待仍有生命的队友进入，已进入的角色不再受输入或镜头拉回。素材、完整提示词及游戏画面见 [混凝土要塞](design/fortress-realistic-v3.md)，流程见 `js/stage-one-exit.mjs`。

第一关河流偶尔有鱼跃出，鱼宽 22 个游戏单位，岸边跃高 30–36，带有出入水的双圈涟漪和水花。同屏最多一条，动画不参与战斗碰撞；素材及节奏见 `design/river-fish.md`。

顶部 HUD 改为两行紧凑布局，暗底渐隐融入场景；空道具槽使用淡刻度，已装备道具保留名称与选中下划线。双人分别显示武器、道具、手雷冷却与强化状态，核心血条使用统一的分段样式。顶部预览见 `design/stage-01-hud-header.png`。

## 第二关高清界面

第二关参照 `H:/download/videoplayback.mp4` 中约 190 秒的走廊、235–242 秒的破墙推进、340 秒的机械控制墙重做显示。保留灰色单点透视墙、深蓝地板、红褐后墙与稳定横向电网，细节密度、角色材质及紧凑中文 HUD 与第一关统一；暂停和静音按钮移到右上侧壁区域，避开近景玩家。

## 第八关：异形巢穴

第八关参考原视频中的紫黑洞穴和红色生物地形，包含跳跃地形、异形爬虫、卵囊、洞穴守卫和末段母巢。中途洞穴守卫的组织连接顶部与地面，完全封住路线；击败后撤去阻挡，才能继续前进，双人和载具同样受到限制。守卫身体可被普通枪械击中，护盾、摩托和巨大化接触不会直接秒杀守卫。

巢穴背景带有缓慢呼吸、局部组织脉光、触须摆动与前后层孢子漂浮。地面和高台复用高清器官纹理：表层血管与下层肠状组织沿不同节奏收缩，表现连续蠕动，平台顶面及碰撞位置保持固定。动效跟随游戏时钟，暂停后画面冻结；动态纹理按尺寸缓存复用，无需下载新的图片资源。

地面爬虫使用六帧动作图集，前后肢交替支撑、抬起和蹬地，身体随步态起伏。每移动 28 像素完成一个循环，转向时同步镜像，停步、暂停和冰冻时保持当前动作；跳起或下落时收拢肢体，落地后继续爬行。图集替换原有单张爬虫资源，保持原来的体型及碰撞范围。

浅色跳跃幼体使用独立的六姿态图集，按实际跳跃状态依次表现站立、屈腿蓄力、蹬腿起跳、空中屈膝、下降伸脚和落地缓冲。所有姿态共用显示比例，地面姿态对齐脚爪，空中收腿时脚爪明显高于身体的脚底参考点。动作计时随暂停和冰冻停止，联机同步空中与落地阶段，落地停步后仍保留原来的朝向。
