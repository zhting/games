# 魂斗罗2026

原「赤焰突击」的合集版本。当前公开试玩开放前四关：「雨林要塞」「地下指挥所」「峡谷瀑布」「地下基地」，支持单人和双人联网同屏。第五关仅限本地预览，后续关卡暂未公开。

在仓库根目录运行 `npm ci`、`npm start`，打开 `/games/contra2026/`。

点击单人闯关或选关后，只准备目标关卡使用的图片、配乐与字体；进入下一关时再显示进度并准备该关资源，加载期间暂停计时。第一关固定使用压缩后的摇滚重制版，正常开启配乐时首次准备共 24 项，不下载其他关卡或旧音乐。共用人物、机关图集与已下载音乐在当前页面内复用，重玩不重复下载；失败可重试，返回标题会取消本次进入。联机加入房间先获知实际关卡，开始时再加载对应资源，玩家二等待完成后应用最新同步画面。

第二关普通闯关使用提供的 `魂斗罗第2关闯关.mp3`，Boss 战沿用原中枢配乐；第三关全程使用 `魂斗罗第3关.mp3`。两首完整曲目转为 48 kHz、64 kbps Opus，分别约 795 KB / 829 KB，只在进入对应关卡时加载。

## 双人联网

1. 进入「2P 联网同屏」，选择起始关卡，创建房间。
2. 将六位房间码或邀请链接交给朋友，对方点击「加入房间」。
3. 房主点击「双人开始」。玩家一为红色，玩家二为蓝色；两台设备使用相同的 WASD / 方向键、J 射击、K 跳跃、I 手雷、L 道具、Q 切换道具，也支持触屏和手柄。

两人共享镜头、关卡进度、分数与有限生命池，各自拥有武器、道具和手雷冷却。默认无限生命。任一方都可以暂停和继续；重开、设置与过关后继续由房主操作。房主切到后台会同步暂停。

联机同样开放第 1–4 关。第二关中枢击败后，所有存活玩家乘侧边升降梯进入第三关；第四关双生投影击败后，所有存活玩家分别登梯到顶部，进入前四关通关界面。可重玩本关或返回标题，旧隐藏关卡存档与秘籍不会开放后续关卡。队友离开后停止闯关，房主可以等待重新加入再开局；房主离开则房间关闭，不进行房主迁移。

后台端点为 `/games/contra2026/ws`，复用根目录 `backend-config.js` 的统一后台配置。房主以 60Hz 运行世界，2P 按键经服务器发送到房主，20Hz 完整快照同步至 2P，保留平台、桥梁和激光命中的对象关系。服务器限制房间人数、消息大小和发送频率，仅允许房主发送快照。

生产前端与后台需一同发布，并为 Nginx 加入 `backend/deploy/nginx-locations.conf` 中的新 WebSocket 路径；仅发布静态前端不能启用生产联机。

红蓝玩家和敌兵统一使用高清手绘角色，站立素材高度由约 168 像素提高到 307–323 像素，皮肤、服装、武器和靴子使用一致的细节密度。跑动使用独立十二帧完整角色，单帧人物高约 330–344 像素，包含落脚、屈膝、交叉、抬膝、蹬地和腾空的中间姿势；斜向射击在腰带位置衔接同风格持枪姿势。停止、翻滚、卧倒、入水和载具分别切换姿势。其他关卡的侧视人形绘制也复用新角色。生成记录见 `design/stage-01-polish-prompts.json`，36 帧对照见 `design/stage-01-run-12-poses.png`。

跑步周期按玩家 42、敌兵 36 个逻辑像素的完整步幅匹配移动速度，降低原先过快的腿部抖动；巨大化同步延长周期。腰部锚点和每行地面基线固定，脚部伸展不会拉动上半身，相邻姿势边角用运行时矢量裁切隔离。左右换向同步转身，腾空和停止不再继续踏步，冻结与恢复保持动画相位。

护盾由透明蓝青能量弧面、环绕高光和命中涟漪组成，随站立、卧倒、翻滚与巨大化调整形状；取消矩形边框。迷彩改为半透明的绿色轮廓与移动扫描带，无敌状态保留角色并加暖金色描边，取消整个人物闪烁消失。效果使用同一角色透明轮廓，不覆盖角色外的矩形区域。代码见 `js/actor-status.mjs`，4K 对照见 `design/stage-01-polish-shield-4k.png`、`design/stage-01-polish-inv-4k.png`。

草皮暴露端采用圆弧下卷、短垂叶与岩台上角过渡，邻接地面保持连续草毯；所有变化只作用于显示轮廓，支撑面不变。

主线玩家死亡后先受击翻倒并下落，碰到地面或平台后切换贴地倒下姿势，停留约 0.3 秒后渐隐，完全消失后再复活。高处死亡会等待落地后的完整过程，桥段消失则继续下落，跌出屏幕直接隐藏。死亡进度与地面支撑一起进入双人快照；生命耗尽的队友遗体消失后保持隐藏。模拟逻辑见 `js/player-death.mjs`，效果见 `design/stage-01-death-sequence.png`。

第一关子弹命中采用材质反馈：金属表面为暖色火星、细碎金属片与少量余烟，核心为蓝白能量闪光，敌兵为较小的碰撞火花和短暂亮起，护盾为蓝色反应。效果锚定碰撞表面并沿射入方向反向散射，要塞原大叉号改为部件局部亮起。单次事件约 0.19–0.29 秒，相邻散弹命中合并，最多同时保留 32 个命中事件；粒子由同步的种子和事件时间绘制。代码见 `js/impact-effects.mjs`，逐帧及连射预览见 `design/stage-01-hit-feedback.png`、`design/stage-01-hit-feedback-4k.png`。

关底要塞保持原设计素材比例，塔顶完整露出，后侧装甲贴住最终镜头右边缘；炮口、核心、墙体阻挡和角色边界共用建筑布局。损毁使用独立透明残骸图集，包含破裂炮管、撕裂装甲、裸露线路与暗色破碎核心；旧机体会移除，余烟与火星随时间消退。核心摧毁时剩余炮口同步变为残骸，损毁时间保存在联机快照中。最新效果见 `design/stage-01-wreck-closeup.png` 和 `design/stage-01-wreck-core.png`。

要塞现使用 `assets/stage1/fortress-detail-v2.webp`，在 1201×1254 的原立面坐标内细化装甲倒角、炮管套筒、嵌入螺栓、液压管线和反应堆内舱，三个损毁部件同步使用新材质。核心摧毁后使用独立的 `fortress-breach-v3.webp`，以不规则钢板断面包住有暖光和管线纵深的暗通道。角色跳入后保持原尺寸，向右移动时被洞壁逐渐遮住，随后进入第二关并保留武器和分数。双人模式等待仍有生命的队友进入，已进入的角色不再受输入或镜头拉回。美术记录见 `design/fortress-detail-v2.md`、`design/fortress-breach-v3.md`，流程见 `js/stage-one-exit.mjs`。

第一关河流偶尔有鱼跃出，鱼宽 22 个游戏单位，岸边跃高 30–36，带有出入水的双圈涟漪和水花。同屏最多一条，动画不参与战斗碰撞；素材及节奏见 `design/river-fish.md`。

顶部 HUD 改为两行紧凑布局，暗底渐隐融入场景；空道具槽使用淡刻度，已装备道具保留名称与选中下划线。双人分别显示武器、道具、手雷冷却与强化状态，核心血条使用统一的分段样式。顶部预览见 `design/stage-01-hud-header.png`。

第一关河面偶尔跃出一条小鱼，沿抛物线回落，出入水时带短暂水花和涟漪。岸边低幅跃起，开阔河段更高；轨迹随关卡时间推进，暂停和镜头移动不会重排。仅为场景细节，素材约 38 KB。记录见 `design/river-fish.md`。

## 参考视频音频

开始页、开场片头、第一关和第二关使用提供的 `H:/download/videoplayback.mp4` 中提取的音频。开始页取 0–5.2 秒，播放一次；开场片头取 5.25–21.224 秒，第一关取 48–99.742 秒，按完整重复乐句循环。第二关走廊取 172–191.170 秒，中枢取 318–329.182 秒；普通房间推进保持连续播放，中枢使用独立音轨，暂停恢复保留播放位置。视频中的作者片头与原作开始页分别处理，素材为录像混音，保留其中已有的音效。

交付文件位于 `assets/audio/`，总计约 1 MB，采用 Opus 立体声、48 kHz、96 kbps，统一响度并处理首尾边缘。`js/reference-music.mjs` 使用 Web Audio 解码缓存与循环播放；暂停保留位置，返回标题重新播放短音乐，并接入现有静音和音乐开关。射击、跳跃等交互音效仍由游戏实时触发。浏览器首次需要点击或按键后启用声音。

截取时间与处理记录见 `design/reference-audio.json`；安装 FFmpeg 后可运行 `python games/contra2026/tools/extract-reference-audio.py` 重新提取，也可追加其他来源文件路径。

## 第五关本地美术试玩

本机打开 `/games/contra2026/?preview=5`，在选关中进入「第五关 · 极地冰原 · 本地试玩」。普通入口、线上地址与多人后台的关卡边界保持不变。

第五关沿 5000 单位长的雪原推进：前段雪林 → 重装履带战车 → 后半段炮兵与林间守军 → 基地上空的飞行堡垒。坦克击毁后留下残骸并放行，只有击败最终堡垒才结算。保留冰面滑行、强风与战车冲撞；有人操作的固定炮位会预警开火，投雷兵从树后探身，手雷落地弹跳后延时爆炸。

大雪持续飘落，阵风改变密度与贴地雪雾。两层云团即使镜头静止也会错速移动，战斗机每隔约 26 秒从远景掠过，单机和编队交替。雪不会盖住敌方弹道。飞行堡垒从高空入场，在横向悬浮时预警瞄准，发射扇形弹幕与落地炸弹；两侧炮座和中央引擎可单独击毁。
